# ESP32 RGBW LED Strip Control System

基于ESP32的智能RGBW灯带控制系统，通过移动应用（App）通过Wi-Fi网络控制，实现丰富的色彩与灯光效果控制。

## 项目概述

本项目采用客户端-服务器（C-S）架构与分层软件设计，确保各模块职责清晰，便于独立开发、测试与维护。

### 整体架构

```
+-------------+     +-------------+     +-------------+
| 移动应用APP | <--> | ESP32开发板 | <--> | RGBW灯带   |
+-------------+     +-------------+     +-------------+
```

### 分层架构设计

#### 硬件层（Hardware Layer）
- **主控制器**：兼容ESP32系列芯片（如ESP32-S3, -C3等）
- **灯带驱动**：支持多种可寻址RGBW灯带芯片（SK6812、WS2812B+W、WS2815等）
- **外设接口**：通过GPIO控制灯带，推荐使用GPIO7（可配置）

#### 固件层（Firmware Layer - 运行于ESP32）
- **硬件抽象层（HAL）**：隔离具体硬件操作，提供统一的GPIO、网络接口
- **网络与服务层**：处理Wi-Fi连接、mDNS服务广播、WebSocket/TCP服务器
- **通信协议层**：定义与App交互的数据格式与指令集
- **数据处理与引擎层**：核心逻辑，解析指令，管理灯光状态，运行效果算法
- **灯带驱动抽象层**：统一不同灯带芯片的驱动接口

#### 客户端层（Client Layer - 运行于移动设备）
- **网络发现层**：自动扫描局域网内的设备
- **通信层**：与ESP32建立连接并收发数据
- **UI呈现层**：提供所有控制界面
- **业务逻辑层**：处理用户输入，生成控制指令

## 硬件连接

### 硬件组件清单

| 组件 | 规格 | 数量 | 用途 |
|------|------|------|------|
| ESP32开发板 | ESP32系列（如ESP32-DevKitC, ESP32-S3, ESP32-C3） | 1 | 主控制器 |
| RGBW LED灯带 | 支持可寻址控制（如SK6812, WS2812B+W, WS2815） | 1 | 发光组件 |
| 电源适配器 | 5V, 2A+（根据灯带长度选择） | 1 | 为ESP32和灯带供电 |
| 面包板 | 标准尺寸 | 1 | 临时连接 |
| 杜邦线 | 公对公、公对母 | 若干 | 连接线路 |
| 电阻 | 220-470Ω | 1 | 数据线串联，保护GPIO |
| 电容 | 100-1000uF | 1 | VCC与GND间并联，抑制上电冲击 |

### 引脚分配

| ESP32引脚 | 功能 | 连接对象 |
|-----------|------|----------|
| GPIO7     | 数据输出 | 灯带DI（通过220-470Ω电阻） |
| 5V        | 电源输出 | 灯带V+ |
| GND       | 接地 | 灯带GND |

### 保护电路

#### 必要性
- **GPIO保护**：防止灯带的反向电压损坏ESP32的GPIO
- **信号稳定**：确保数据信号的稳定性，减少干扰
- **电源稳定**：抑制上电时的电流冲击

#### 电路设计

```
ESP32 GPIO7 --[220-470Ω电阻]--+--[灯带DI]
                               |
+5V ---------------------------+--[灯带V+]
                               |
GND ---------------------------+--[灯带GND]
                               |
+5V --[100-1000uF电容]-- GND
```

### 电源连接

#### 注意事项
1. **电源容量**：确保电源适配器能够提供足够的电流，一般每米RGBW灯带需要约0.5A电流
2. **电源稳定性**：使用稳压电源，避免电压波动
3. **接地**：确保所有设备接地良好，避免干扰
4. **共地**：ESP32和灯带必须共地，否则可能导致通信失败

#### 推荐电源配置
- 灯带长度 ≤ 2米：5V/2A电源适配器
- 灯带长度 2-5米：5V/5A电源适配器
- 灯带长度 > 5米：考虑使用分布式电源

### 支持的灯带芯片

#### 主要支持
- **SK6812**：原生支持RGBW四通道
- **WS2812B+W**：WS2812B基础上增加白色通道
- **WS2815**：高压版本，支持更长距离传输

#### 连接差异
- **SK6812**：直接连接，使用RGBW数据格式
- **WS2812B+W**：需要确认W通道的实现方式
- **WS2815**：可使用更高电压（12V），但需要相应的电源

### 硬件组装步骤

1. **准备组件**：收集所有必要的硬件组件
2. **连接保护电路**：在ESP32的GPIO7和灯带DI之间串联220-470Ω电阻
3. **连接电容**：在电源的VCC和GND之间并联100-1000uF电容
4. **连接灯带**：将RGBW灯带的V+接5V，GND接GND，DI接保护电阻的另一端
5. **连接电源**：将电源适配器与ESP32和灯带连接
6. **测试连接**：确保所有连接正确，无短路

## 通信协议

### 数据格式（JSON）

#### 设置静态颜色

```json
{
  "cmd": "static",
  "color": {
    "r": 255,
    "g": 100,
    "b": 50,
    "w": 0
  },
  "brightness": 80
}
```

#### 设置效果

```json
{
  "cmd": "effect",
  "name": "breath",
  "speed": 50,
  "color": {
    "r": 255,
    "g": 0,
    "b": 0,
    "w": 0
  },
  "brightness": 80
}
```

#### 开关控制

```json
{
  "cmd": "switch",
  "on": true
}
```

#### 获取状态

```json
{
  "cmd": "get_status"
}
```

### 接收状态格式

```json
{
  "cmd": "status",
  "on": true,
  "mode": 0,
  "color": {
    "r": 255,
    "g": 100,
    "b": 50,
    "w": 0
  },
  "brightness": 80,
  "speed": 50
}
```

### 命令类型

- `static`：设置静态颜色
- `effect`：设置动态效果
- `switch`：开关控制
- `get_status`：获取当前状态
- `ping`：心跳包（应用端发送）
- `pong`：心跳响应（设备端发送）

## 故障排除

| 问题 | 可能原因 | 解决方案 |
|------|---------|----------|
| 灯带不亮 | 电源未连接 | 检查电源连接 |
|  | 数据信号异常 | 检查GPIO连接和保护电阻 |
|  | 灯带损坏 | 测试灯带是否正常 |
| 颜色异常 | 数据格式错误 | 检查灯带芯片类型和数据格式 |
|  | 连接顺序错误 | 检查RGBW通道顺序 |
| 闪烁 | 电源不稳定 | 使用稳压电源，增加电容 |
|  | 信号干扰 | 缩短数据线长度，增加屏蔽 |
| 部分灯珠不亮 | 灯带损坏 | 检查灯带连接和灯珠状态 |
|  | 电源不足 | 使用更大容量的电源 |

## 安全注意事项

1. **电源安全**：不要使用超过额定电压的电源
2. **散热**：确保ESP32和MOSFET（如果使用）有足够的散热空间
3. **短路保护**：检查所有连接，避免短路
4. **绝缘**：确保裸露的电线有适当的绝缘
5. **电流限制**：不要超过ESP32 GPIO的最大输出电流（一般为20mA）
