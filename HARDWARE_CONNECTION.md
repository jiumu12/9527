# ESP32 RGBW LED Strip Hardware Connection Guide

## 硬件组件清单

| 组件 | 规格 | 数量 | 用途 |
|------|------|------|------|
| ESP32开发板 | ESP32-DevKitC | 1 | 主控制器 |
| RGBW LED灯带 | 5V, 4通道 | 1 | 发光组件 |
| 电源适配器 | 5V, 2A+ | 1 | 为ESP32和灯带供电 |
| 面包板 | 标准尺寸 | 1 | 临时连接 |
| 杜邦线 | 公对公、公对母 | 若干 | 连接线路 |
|  MOSFET驱动板 | IRF520或类似 | 4 | 驱动RGBW通道 |

## 引脚分配

| ESP32引脚 | 功能 | 连接对象 |
|-----------|------|----------|
| GPIO23    | PWM输出 | RGBW灯带R通道 |
| GPIO22    | PWM输出 | RGBW灯带G通道 |
| GPIO21    | PWM输出 | RGBW灯带B通道 |
| GPIO19    | PWM输出 | RGBW灯带W通道 |
| 5V        | 电源输出 | 灯带V+ |
| GND       | 接地 | 灯带GND |

## MOSFET驱动电路

由于ESP32的GPIO引脚输出电流有限，无法直接驱动RGBW灯带，需要使用MOSFET驱动电路。

## 电源连接

### 注意事项
1. **电源容量**：确保电源适配器能够提供足够的电流，一般每米RGBW灯带需要约0.5A电流
2. **电源稳定性**：使用稳压电源，避免电压波动
3. **接地**：确保所有设备接地良好，避免干扰

### 推荐电源配置
- 灯带长度 ≤ 2米：5V/2A电源适配器
- 灯带长度 2-5米：5V/5A电源适配器
- 灯带长度 > 5米：考虑使用分布式电源

## 硬件组装步骤

1. **准备组件**：收集所有必要的硬件组件
2. **连接MOSFET**：将MOSFET驱动板与ESP32连接
3. **连接灯带**：将RGBW灯带与MOSFET驱动板连接
4. **连接电源**：将电源适配器与ESP32和灯带连接
5. **测试连接**：确保所有连接正确，无短路

## 安全注意事项

1. **电源安全**：不要使用超过额定电压的电源
2. **散热**：确保MOSFET有足够的散热空间
3. **短路保护**：检查所有连接，避免短路
4. **绝缘**：确保裸露的电线有适当的绝缘

## 故障排除

| 问题 | 可能原因 | 解决方案 |
|------|---------|----------|
| 灯带不亮 | 电源未连接 | 检查电源连接 |
|  | MOSFET损坏 | 更换MOSFET |
|  | GPIO引脚配置错误 | 检查代码中的引脚配置 |
| 颜色异常 | 通道连接错误 | 检查RGBW通道连接 |
|  | PWM信号异常 | 检查ESP32的PWM输出 |
| 闪烁 | 电源不稳定 | 使用稳压电源 |
|  | WiFi干扰 | 优化WiFi信号 |
